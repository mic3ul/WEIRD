WEIRD

WEIRD is a modular security testing toolkit that combines network reconnaissance, web security assessment, payload generation, and diagnostic utilities in a unified interface.

Features

- Network and DNS reconnaissance
- Web vulnerability assessment
- Payload generation and listener utilities
- Network diagnostics and security testing
- Dependency management and results storage

Use this project only on systems you own or have explicit authorization to test.
